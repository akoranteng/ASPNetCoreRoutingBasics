# MvcRoutingDemo

This project demonstrates routing in ASP.NET Core using the **MVC controller/action model**.  
It focuses on attribute routing, conventional routing, route templates, route constraints, and how MVC integrates with the ASP.NET Core routing pipeline.

---

## 📘 What You Will Learn

By exploring this project, you will understand:

- How MVC uses **controller/action routing**
- How to define **attribute routes** with templates and parameters
- How to use **conventional routing** in `Program.cs`
- How route constraints work (e.g., `{id:int}`)
- How Tag Helpers generate correct URLs based on routing
- How MVC routing compares to Minimal APIs and Razor Pages

This project builds on the concepts introduced in the MinimalApiDemo and prepares learners for Razor Pages routing.

---

## 🧩 Key Routing Examples

This project includes examples of:

- Controller/action routing  
- Attribute routing with parameters  
- Route constraints  
- Default routes and custom routes  
- URL generation using Tag Helpers  
- Returning views and JSON results  

Each example is designed to be clear, focused, and easy to extend.
