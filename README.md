# ASP.NET Core Routing Basics

A collection of Minimal API, MVC, and Razor Pages routing demos built to teach classic ASP.NET Core routing fundamentals.  
This repository forms the foundation for understanding how routing works in ASP.NET Core before moving into modern Blazor routing in the companion repository.

---

## 📘 Overview

This solution contains **three focused sample projects**, each demonstrating a different routing model in ASP.NET Core:

1. **MinimalApiDemo**  
   - Endpoint routing  
   - Route templates  
   - Route constraints  
   - Lightweight HTTP handlers

2. **MvcRoutingDemo**  
   - Controller/action routing  
   - Attribute routing  
   - Tag Helpers  
   - Views and partials

3. **RazorPagesRoutingDemo**  
   - Folder‑based routing  
   - Page handlers  
   - Route parameters in Razor Pages

Each project includes its own `README.md` with examples, diagrams, and learning objectives.

---

## 🎯 Learning Objectives

By working through this repository, you will:

- Understand how ASP.NET Core maps URLs to handlers  
- Learn the differences between Minimal API, MVC, and Razor Pages routing  
- Explore route templates, constraints, and parameter binding  
- Build a mental model of **Endpoint Routing**, the foundation for all modern .NET routing  
- Prepare for Blazor’s component‑based routing model
